two oil tankers ablaze in the Strait of Hormuz, Houthi strikes on Saudi oil,
Ukrainian drones burning two Russian refineries, Asia's markets plunging as
the Dow tops 50,000, Huawei convicted in the US, a Pacific security treaty,

15 stories across 6 continents, pinned on a light world map.

## Entry

- `main.py` — Python 3.13, standard library only. Copies `entry.png` to
  `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR`). Deterministic: two runs
  write byte-identical files.
- `entry.png` — 1024×1024, 134,572 bytes, drawn at build time from news
  verified on 25 November 2026 (Just Security Early Edition, Reuters,
  Investopedia).

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`
